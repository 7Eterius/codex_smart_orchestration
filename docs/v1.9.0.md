# v1.9.0: operator/judge cost routing

v1.9.0 separates high-volume mechanical agent work from the smaller number of turns
that need expensive judgment.

## Model map

- Simple: GPT-6 Luna Low
- Routine: GPT-6 Luna High
- Default: GPT-6 Luna xhigh
- Senior: GPT-6 Sol xhigh
- Tester: GPT-6 Luna High
- Companion: GPT-6 Luna Medium
- Investigator: GPT-6 Luna xhigh
- Archivist: GPT-6 Luna Medium

Max is not used by an automatic named role. It remains available to an owner whose
representative evaluations show a material gain over xhigh.

## Operator versus judge

Simple is the low-cost operator lane. It can read webpages, navigate known
browser/desktop flows, change explicit development settings through a GUI, inspect
DOM/console/network state, capture screenshots and check explicit observable criteria.

The boundary is judgment. Simple must not decide whether a design is good, invent an
interaction model, redefine hierarchy or perform ambiguous visual critique. Those
decisions remain with main/Senior Sol. Astra is owner-selected for the rare case where
difficult spatial or visual judgment itself benefits from the flagship.

## Verification economy

A Browser, screenshot or Computer Use task does not automatically justify an
independent Tester. Deterministic GUI evidence can be collected by Simple. Tester is
reserved for behavior, state, integration, accessibility, shared-contract or
cross-boundary work where a second judgment adds information.

Structured evidence is preferred before screenshots when it answers the question:
source/tests, DOM, console and network state first; visual evidence when appearance or
running interaction is actually under test.

## Standalone repository cleanup

The active tree now represents Smart Orchestration itself rather than preserving the
old codex_workflow implementation. Project bootstrap/install/enable/disable machinery,
Heavy/Medium route shims, project-doc templates, old release packaging, token-report
and efficiency modules, benchmark media, historical ZIPs and version-by-version
compatibility tests were removed. Git history remains the archive for those eras.

The current test suite covers the current package, routing map, prompt budgets, global
installation, configuration preservation, retired-owned-file cleanup, exact rollback,
idempotent reapply and conflict handling.
