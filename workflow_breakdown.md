# Smart Orchestration architecture

The single canonical policy is `codex_workflow/smart_orchestration.md`.
See `README.md` for the global installer and role table, and
`docs/smart_orchestration.md` for escalation, memory and compatibility contracts.

The former Heavy/Medium routes are compatibility redirects, not user-selectable
workflows. Main plans and audits; bounded roles implement or investigate as
needed. Archivist maintains concise permanent state and history at meaningful
checkpoints. Installation is global; project memory is local and reused without
requiring a project-specific workflow install.

Archived Quality Economy documents describe previous releases, not the active
Smart Orchestration contract. Applicable project product/safety instructions and
explicit owner decisions remain authoritative.
